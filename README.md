# SYSTEM DESCRIPTION

JUBULU Food Kiosk is a C# console-based food ordering and cashier management system. It is designed to provide an organized process for customers to place food orders and make payments, while allowing cashiers to retrieve completed transactions and monitor sales.

The system has two main user views: Customer View and Cashier View. In Customer View, users can browse the food menu, select items, enter quantities, review or cancel their orders, and complete their payments. Once payment is successful, the system generates a receipt with a unique Order ID and saves the transaction record.

In Cashier View, cashiers can search for paid orders using their Order IDs and view the sales report, which displays the number of completed orders and total sales. The system stores transaction records in a text file for future retrieval.

# SYSTEM INSTRUCTIONS

Follow the instructions below when using the JUBULU Food Kiosk system.

## A. General Instructions

1. Make sure that the application is properly opened and running.
2. Wait for the Main Menu to appear.
3. Enter the number corresponding to your preferred option.
4. Follow the instructions displayed on the screen.
5. Enter valid information whenever the system requests an input.

## B. Customer Instructions

1. Select Customer View from the Main Menu.
2. View the available food items and their prices.
3. Select the desired food item.
4. Enter the quantity for each selected item.
5. Add more items if needed.
6. Review the order and check the total amount.
7. Choose whether to add more items, cancel the order, or confirm it.
8. If the order is confirmed, enter the cash payment.
9. Make sure the payment is sufficient to cover the total amount.
10. Wait for the system to calculate the change and generate the receipt.
11. Keep the Order ID for future reference.

## C. Cashier Instructions

1. Select Cashier View from the Main Menu.
2. Choose the desired cashier function.
3. To retrieve a paid order, select Find Paid Order.
4. Enter the customer's Order ID.
5. Wait for the system to search the saved transaction records.
6. If the Order ID is found, review the displayed receipt.
7. To monitor sales, select View Sales Report.
8. Review the number of completed orders and total sales displayed by the system.
9. Select Back to return to the Main Menu.

## D. Important Reminders

1. Enter the correct menu option when navigating the system.
2. Enter valid quantities when ordering food.
3. Make sure that the cash payment is sufficient before completing a transaction.
4. Keep the generated Order ID because it is needed when retrieving a paid order.
5. Do not manually modify the saved transaction records because they are used by the system to retrieve orders and calculate sales.
